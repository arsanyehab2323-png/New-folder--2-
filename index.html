Problem 1: Linear Regression Parameter Update (Gradient Descent)

💡 دليل السؤال (المحاضرة 2 - Linear Regression with One Variable):

  • المحاضرة: المحاضرة الثانية.
  • الكلمات المفتاحية في السؤال: Assume θ₀, θ₁, α / Compute total error / Update values of θ₀ and θ₁ after first iteration.
  • القانون المستخدم:
    1. دالة التنبؤ: h(x) = θ₀ + θ₁x
    2. دالة التكلفة (MSE): J(θ) = (1 / 2m) * Σ(h(x) - y)²
    3. قانون تحديث θ₀: θ₀_new = θ₀ - α * (1/m) * Σ(h(x) - y)
    4. قانون تحديث θ₁: θ₁_new = θ₁ - α * (1/m) * Σ[(h(x) - y) * x]

Question Statement:

Consider the following training data for linear regression:

Xy
23
34
45

You are using linear regression and assume θ₀ = 2, θ₁ = 2, and α = 0.1.

Compute the total error and update the values of θ₀ and θ₁ after the first iteration.

Step-by-Step Solution:

1. Initial Hypothesis Equation:
h_θ(x) = θ₀ + θ₁x = 2 + 2x

2. Compute Predictions and Errors for each sample (m = 3):

  • Sample 1 (x = 2, y = 3):
    h(2) = 2 + 2(2) = 6
    (h - y) = 6 - 3 = 3
    (h - y)² = 9
  • Sample 2 (x = 3, y = 4):
    h(3) = 2 + 2(3) = 8
    (h - y) = 8 - 4 = 4
    (h - y)² = 16
  • Sample 3 (x = 4, y = 5):
    h(4) = 2 + 2(4) = 10
    (h - y) = 10 - 5 = 5
    (h - y)² = 25

3. Calculate Total Cost Function (MSE Error):
Σ(h - y) = 3 + 4 + 5 = 12
Σ(h - y)² = 9 + 16 + 25 = 50
J(θ₀, θ₁) = (1 / 2m) * Σ(h - y)² = (1 / (2 * 3)) * 50 = 50 / 6 = 8.333

4. Calculate Term for θ₁ Update:
Σ[(h - y) * x] = (3 * 2) + (4 * 3) + (5 * 4) = 6 + 12 + 20 = 38

5. Update Parameters θ₀ and θ₁:
θ₀_new = θ₀ - α * (1/m) * Σ(h - y) = 2 - 0.1 * (1/3) * (12) = 2 - 0.4 = 1.6
θ₁_new = θ₁ - α * (1/m) * Σ[(h - y) * x] = 2 - 0.1 * (1/3) * (38) = 2 - 1.2667 = 0.7333

Final Answer: Total Error J(θ) = 8.333, Updated Parameters: θ₀ = 1.6, θ₁ = 0.7333

Problem 4: K-Nearest Neighbors (KNN) Regression

💡 دليل السؤال (المحاضرة 4 - KNN Regression):

  • المحاضرة: المحاضرة الرابعة.
  • الكلمات المفتاحية في السؤال: KNN Regression / Predict weight for new point (2, 1) / K = 3.
  • القانون المستخدم:
    1. حساب مسافة إقليدس لكل النقاط: d = √[(x₁ - x₁_new)² + (x₂ - x₂_new)²]
    2. اختيار أول K جيران.
    3. حساب المتوسط الحسابي لقيم المستهدف: Predicted Value = (y₁ + y₂ + ... + y_k) / K

Given the dataset below, predict the target weight for a new data point (x1 = 2, x2 = 1) using KNN Regression with K = 3:

x1x2weight (y)

Step-by-Step Solution:

Calculate Euclidean distance from (2, 1) to all dataset points:

  • Point 1 (7, 7): d = √[(7-2)² + (7-1)²] = √[25 + 36] = √61 ≈ 7.81 (Rank 4)
  • Point 2 (7, 4): d = √[(7-2)² + (4-1)²] = √[25 + 9] = √34 ≈ 5.83 (Rank 3)
  • Point 3 (3, 4): d = √[(3-2)² + (4-1)²] = √[1 + 9] = √10 ≈ 3.16 (Rank 2)

KNN Regression Average Prediction:
Predicted Weight = (weight_4 + weight_3 + weight_2) / K = (1 + 2 + 3) / 3 = 6 / 3 = 2.0

Problem 5: Naive Bayes Classification

💡 دليل السؤال (المحاضرة 5 - Naive Bayes Classifier):

  • المحاضرة: المحاضرة الخامسة.
  • الكلمات المفتاحية في السؤال: Estimate conditional probabilities / Predict class for new instance / PlayTennis or Species.
  • القانون المستخدم:
    1. الاحتمال القبلي: P(Class) = Count(Class) / Total_Samples
    2. الاحتمال الشرطي المركب: P(Class | X) ∝ P(Class) * P(x₁|Class) * P(x₂|Class) * ... * P(xₙ|Class)
    3. المقارنة والقرار للفئة ذات الاحتمال الأعلى.

Question Statement:

Given 14 training examples (9 PlayTennis = Yes, 5 PlayTennis = No), classify the new instance:

X_new = <Outlook = sunny, Temperature = cool, Humidity = high, Wind = strong>

Step-by-Step Solution:

1. Prior Probabilities:
P(PlayTennis = yes) = 9 / 14 = 0.643
P(PlayTennis = no) = 5 / 14 = 0.357

2. Conditional Probabilities for each feature:

Feature ValueP(Feature | Yes)P(Feature | No)
Outlook = sunny2 / 93 / 5
Temperature = cool3 / 91 / 5
Humidity = high3 / 94 / 5
Wind = strong3 / 93 / 5

3. Posterior Probability Calculations:

P(yes | X_new) ∝ P(yes) * P(sunny|yes) * P(cool|yes) * P(high|yes) * P(strong|yes)
= (9/14) * (2/9) * (3/9) * (3/9) * (3/9) = (0.643) * (0.222) * (0.333) * (0.333) * (0.333) ≈ 0.0053

P(no | X_new) ∝ P(no) * P(sunny|no) * P(cool|no) * P(high|no) * P(strong|no)
= (5/14) * (3/5) * (1/5) * (4/5) * (3/5) = (0.357) * (0.600) * (0.200) * (0.800) * (0.600) ≈ 0.0206

4. Comparison and Final Decision:
Since P(no | X_new) > P(yes | X_new) (0.0206 > 0.0053), the predicted class for the new instance is No (PlayTennis = No).

Problem 6: Confusion Matrix Evaluation Metrics

💡 دليل السؤال (المحاضرة 6 - Classification Metrics):

  • المحاضرة: المحاضرة السادسة.
  • الكلمات المفتاحية في السؤال: Evaluate accuracy, precision, recall, F1-score / Confusion Matrix.
  • القانون المستخدم:
    1. Accuracy = (TP + TN) / Total
    2. Precision = TP / (TP + FP)
    3. Recall = TP / (TP + FN)
    4. F1-Score = 2 * (Precision * Recall) / (Precision + Recall)

Question Statement:

Solve the following confusion matrix by evaluating Accuracy, Precision, Recall, and F1-score for predicting whether an email is "Spam" or "Not Spam" (Test set of 200 emails):

Actual SpamActual Not Spam
Predicted SpamTP = 120FP = 20
Predicted Not SpamFN = 10TN = 50

Step-by-Step Solution:

1. Accuracy:
Accuracy = (TP + TN) / Total = (120 + 50) / 200 = 170 / 200 = 0.85 (85%)

2. Precision:
Precision = TP / (TP + FP) = 120 / (120 + 20) = 120 / 140 ≈ 0.857 (85.7%)

3. Recall:
Recall = TP / (TP + FN) = 120 / (120 + 10) = 120 / 130 ≈ 0.923 (92.3%)

4. F1-Score:
F1-score = 2 * (Precision * Recall) / (Precision + Recall)
= 2 * (0.857 * 0.923) / (0.857 + 0.923) = 1.5819 / 1.780 ≈ 0.889 (88.9%)

Problem 7: Data Smoothing & Binning

💡 دليل السؤال (المحاضرة 1 - Data Preprocessing & Smoothing):

  • المحاضرة: المحاضرة الأولى.
  • الكلمات المفتاحية في السؤال: Equal-frequency (equi-depth) binning / Smoothing by bin means / boundaries.
  • القانون المستخدم:
    1. عدد العناصر بكل فئة = Total Items / Number of Bins
    2. Smoothing by Bin Means: استبدال كل عنصر في الفئة بوسط الفئة الحسابي.
    3. Smoothing by Boundaries: استبدال العناصر الداخلية بأقرب قيمة حدية (Min أو Max).

Question Statement:

Sorted price data: [4, 8, 9, 15, 21, 21, 24, 25, 26, 28, 29, 34] (12 elements).

Partition data into 3 equal-frequency bins, then smooth by bin means and bin boundaries.

Step-by-Step Solution:

1. Partitioning into 3 Equal-Frequency Bins (12 / 3 = 4 elements per bin):

  • Bin 1: 4, 8, 9, 15
  • Bin 2: 21, 21, 24, 25
  • Bin 3: 26, 28, 29, 34

2. Smoothing by Bin Means:

  • Mean of Bin 1 = (4 + 8 + 9 + 15) / 4 = 36 / 4 = 9 → Bin 1: [9, 9, 9, 9]
  • Mean of Bin 2 = (21 + 21 + 24 + 25) / 4 = 91 / 4 = 22.75 ≈ 23 → Bin 2: [23, 23, 23, 23]
  • Mean of Bin 3 = (26 + 28 + 29 + 34) / 4 = 117 / 4 = 29.25 ≈ 29 → Bin 3: [29, 29, 29, 29]

3. Smoothing by Bin Boundaries:

  • Bin 1 Boundaries [4, 15]: 8 is closer to 4; 9 is closer to 4 → Bin 1: [4, 4, 4, 15]
  • Bin 2 Boundaries [21, 25]: 24 is closer to 25 → Bin 2: [21, 21, 25, 25]
  • Bin 3 Boundaries [26, 34]: 28 is closer to 26; 29 is closer to 26 → Bin 3: [26, 26, 26, 34]

Problem 8: Data Normalization (Min-Max & Z-Score)

💡 دليل السؤال (المحاضرة 1 - Data Normalization):

  • المحاضرة: المحاضرة الأولى.
  • الكلمات المفتاحية في السؤال: Min-max normalization / Z-score normalization / Decimal scaling.
  • القانون المستخدم:
    1. Min-Max: v' = [(v - min) / (max - min)] * (new_max - new_min) + new_min
    2. Z-score: v' = (v - μ) / σ
    3. Decimal Scaling: v' = v / 10^j

Question Statement:

Suppose that an attribute income ranges from $12,000 to $98,000.

a) Map income value $73,600 into the range [0.0, 1.0] using Min-Max Normalization.

b) Normalize income $73,600 using Z-Score Normalization given mean μ = 54,000 and standard deviation σ = 16,000.

Step-by-Step Solution:

a) Min-Max Normalization:
Formula: v' = [(v - min) / (max - min)] * (new_max - new_min) + new_min
v' = [(73,600 - 12,000) / (98,000 - 12,000)] * (1.0 - 0.0) + 0.0
v' = [61,600 / 86,000] * 1.0 = 0.7163

b) Z-Score Normalization:
Formula: v' = (v - μ) / σ
v' = (73,600 - 54,000) / 16,000 = 19,600 / 16,000 = 1.225

📌 Complete Machine Learning Formula Sheet (All Lectures)

1. Linear Regression Equations (Lectures 2 & 3)

  • Hypothesis (Single Variable): h_θ(x) = θ₀ + θ₁x
  • Hypothesis (Multiple Variables): h_θ(x) = θᵀX = θ₀x₀ + θ₁x₁ + θ₂x₂ + ... + θₙxₙ (where x₀ = 1)
  • Cost Function (MSE): J(θ) = (1 / 2m) * Σ(h_θ(x⁽ⁱ⁾) - y⁽ⁱ⁾)²
  • Gradient Descent Update: θⱼ := θⱼ - α * (1/m) * Σ[(h_θ(x⁽ⁱ⁾) - y⁽ⁱ⁾) * xⱼ⁽ⁱ⁾]

2. Distance & Dissimilarity Measures (Lectures 1 & 4)

  • Euclidean Distance (L2 norm): d(i, j) = √[ Σ (x_if - x_jf)² ]
  • Manhattan Distance (L1 norm): d(i, j) = Σ |x_if - x_jf|
  • Nominal Attribute Dissimilarity: d(i, j) = (p - m) / p (p = total attributes, m = matching attributes)

3. Classification Evaluation Metrics (Lecture 6)

  • Accuracy: Accuracy = (TP + TN) / (TP + TN + FP + FN)
  • Precision: Precision = TP / (TP + FP)
  • Recall: Recall = TP / (TP + FN)
  • F1-Score: F1-score = 2 * (Precision * Recall) / (Precision + Recall)

4. Naive Bayes & Regularization (Lectures 5 & 6)

  • Bayes Rule: P(Y | X) = [ P(Y) * P(X | Y) ] / P(X)
  • Ridge Regularization (L2) Cost: J(θ) = (1 / 2m) [ Σ(h_θ(x⁽ⁱ⁾) - y⁽ⁱ⁾)² + λ Σ θⱼ² ]
  • Regularized Logistic Cost: J(θ) = - (1/m) Σ [ y log(h) + (1-y) log(1-h) ] + (λ / 2m) Σ θⱼ²
